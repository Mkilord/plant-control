# PlantControl

[![License: GPL v3](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)
![Architectures](https://img.shields.io/badge/arch-amd64%20%7C%20aarch64-informational)

[English](README.md) · **Русский**

Дополнение (add-on) Home Assistant для адресного полива растений. Вы описываете
свои поливальные машины — бак, насос, трубки и клапаны к каждому растению, — а
PlantControl рассчитывает, сколько должен работать насос ради нужной дозы, поливает
по расписанию, ведёт очередь, чтобы машины не перегружали питание, и не даёт
поливать, когда что-то не в порядке.

От Home Assistant нужны только выключатели насосов и клапанов: любое реле, которое
видно как сущность `switch`.

## Возможности

- **Поливальные машины** — форма и объём бака, модель расхода насоса (постоянная,
  линейная или по таблице замеров), трубки и коллектор клапанов, открыт не больше
  одного выхода.
- **Полив по дозе** — вы задаёте миллилитры, PlantControl сам считает время работы
  с учётом воды в трубках и напора.
- **Расписания** — по дням недели или раз в N дней, для каждого растения.
- **Очередь** — одна машина поливает за раз, предел по группе питания, ручные заявки
  идут первыми.
- **Проблемы** — недоступен насос или клапан, неизвестно состояние насоса, пустой
  бак, нет связи с Home Assistant. Пока открыта блокирующая проблема, полив
  невозможен.
- **Пуш-уведомления** на телефоны через приложение Home Assistant (Companion),
  с тихими часами и срочными сообщениями.
- **MQTT discovery** — каждая машина становится устройством в Home Assistant:
  уровень бака, состояние, последний полив, кнопка «Полить» на каждое растение.
- Интерфейс на русском и английском, светлая и тёмная темы, открывается внутри
  Home Assistant (Ingress).

## Что нужно

- Home Assistant OS или Supervised: дополнения работают только с Supervisor.
- Машина `amd64` или `aarch64` (Raspberry Pi 4/5 в 64-битной системе, мини-ПК x86
  и т. п.).
- Реле насосов и клапанов в Home Assistant в виде сущностей `switch`.
- По желанию: дополнение Mosquitto broker для устройств MQTT, приложение Companion
  для пушей.

## Установка

[![Добавить репозиторий в Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FMkilord%2Fplant-control)

Или вручную:

1. В Home Assistant откройте **Настройки → Дополнения → Магазин дополнений**.
2. Меню справа сверху → **Репозитории**, добавьте
   `https://github.com/Mkilord/plant-control` и закройте окно.
3. Найдите **PlantControl** в магазине, нажмите **Установить**, затем **Запустить**.
4. Включите **Показывать на боковой панели** и откройте PlantControl.

### Каналы выпусков

| Канал | Адрес репозитория | Для кого |
| --- | --- | --- |
| Стабильный | `https://github.com/Mkilord/plant-control` | Для постоянного использования |
| Бета | `https://github.com/Mkilord/plant-control#beta` | Попробовать новое раньше других |
| Dev | `https://github.com/Mkilord/plant-control#dev-channel` | Проверять каждое изменение сразу |

В бета-версиях бывают ошибки, в dev-версиях тем более: каждый пуш в `dev`
становится новой dev-версией. Перед сменой канала сделайте резервную копию.
Добавляйте только один из репозиториев.

## Безопасность

PlantControl включает и выключает насосы и клапаны. Отказать может что угодно:
программа, Wi-Fi-реле, сам Home Assistant. Ставьте защиту, которая не зависит от
дополнения, — поплавковый выключатель, насос с защитой от сухого хода, реле
времени, — особенно если полив идёт без присмотра.
