# Add-on PlantControl

Адресный полив растений в Home Assistant: свои поливальные машины, расписания,
очередь поливов и проблемы. От Home Assistant нужны только реле насосов и клапанов.

## Установка

Add-on ставится как локальный: содержимое репозитория кладётся в папку `addons`
на машине с Home Assistant (например `/addons/plant_control`), после чего он
появляется в разделе Settings - Add-ons - Add-on Store как локальный add-on.

Интерфейс открывается внутри Home Assistant (Ingress), отдельный порт не нужен.

## Настройки

| Настройка | Что делает |
| --- | --- |
| `log_level` | Подробность журнала. |
| `timezone` | Часовой пояс расписаний и тихих часов. |
| `mqtt_enabled` | Создавать сущности машин в Home Assistant через MQTT discovery. |
| `notify_enabled` | Отправлять уведомления. |
| `notify_service` | Чем уведомлять: `persistent_notification.create` или `notify.<сервис>`. |
| `notify_events` | Виды событий через запятую. Пусто - сбои и проблемы. |
| `notify_quiet_from`, `notify_quiet_to` | Тихие часы, например `23:00` и `07:00`. Срочное приходит и в них. |

Адрес брокера MQTT add-on спрашивает у Supervisor сам.

## Что появляется в Home Assistant

Каждая машина становится устройством: остаток воды и заполнение бака, состояние,
время последнего полива, признак проблемы, кнопка "Полить" на каждое растение,
поле дозы и кнопка "Бак залит" - её удобно нажимать автоматизацией по метке NFC.

События на шине (`plant_control_watering_done`, `plant_control_watering_failed`,
`plant_control_problem_opened` и другие) позволяют автоматизациям реагировать самим.

## Разработка

Бэкенд и фронт запускаются отдельно, без Home Assistant: адрес и долгоживущий
токен задаются в `addon/backend/.env`. Подробности - в README репозитория.
